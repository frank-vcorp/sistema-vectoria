# Guía de Marca VectorIA (Adobe Express)

Esta guía contiene los activos necesarios para configurar la identidad de marca de VectorIA en Adobe Express.

## 1. Logotipo Principal
- **Archivo**: `VectorIA-Logo-Oficial-Transparente.png`
- **Uso**: Subir en la sección "Logotipos". Este archivo tiene fondo transparente para usarse sobre cualquier color.

## 2. Paleta de Colores (HEX)
Copia y pega estos códigos en la sección "Colores" de tu marca en Adobe Express:

| Color | Código HEX | Uso Sugerido |
|-------|------------|--------------|
| **Azul Navy Profundo** | `#0A1F44` | Color principal para textos y wordmark. |
| **Naranja Quemado** | `#D35400` | Color de acento para el isotipo y llamadas a la acción. |
| **Blanco Puro** | `#FFFFFF` | Fondos y espacios negativos. |
| **Gris Carbón** | `#2C3E50` | Textos secundarios o variantes de logo. |

## 3. Tipografía Sugerida
Para mantener la coherencia con el logo (Sans-Serif Moderna), busca estas fuentes dentro de Adobe Express:

- **Para Títulos**: *Montserrat* (Bold/Extra Bold) o *Inter* (Semi Bold).
- **Para Cuerpo de Texto**: *Montserrat* (Regular) o *Open Sans*.
- **Alternativa Premium**: *Futura* o *Avenir*.

## 4. Estilo Visual
- **Menos es más**: Prioriza el espacio en blanco.
- **Dirección**: Usa el isotipo de chevron como elemento gráfico sutil en esquinas o como viñetas para reforzar el concepto de "Vector".
